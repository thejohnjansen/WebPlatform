# Explainers

Use this folder for draft explainers and notes.

Start from `explainer-template.md` to keep a structure consistent with the style used in MicrosoftEdge/MSEdgeExplainers.

## Suggested naming

- `YYYY-MM-DD-topic.md` for date-based drafts
- `topic-vN.md` for iterative revisions

## Suggested structure for each explainer

```md
# Title

## Problem

## Goals

## Proposal

## Open Questions

## Next Steps
```
