# Prototypes

This folder is for quick front-end experiments.

## Per-prototype structure

Create one folder per prototype:

- `prototypes/<prototype-name>/index.html`
- `prototypes/<prototype-name>/styles.css`
- `prototypes/<prototype-name>/script.js`

## Local testing

Open `index.html` directly, or serve this repo with a local static server for cleaner relative-path behavior.
