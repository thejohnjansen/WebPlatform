CSS Grid Lanes

Each card below is placed by display: grid-lanes — the browser flows items into whichever lane is shortest, with no JavaScript and no manual column assignment.

display: grid-lanes

The new display value that enables masonry-style layout natively in CSS. Items flow into the shortest available lane automatically.

grid-template-columns

Define the lanes. Use repeat(auto-fill, minmax(250px, 1fr)) to get responsive columns without any media queries.

flow-tolerance

Controls how picky the placement algorithm is. The default is 1em, meaning items within 1em of each other in remaining space are treated as a tie and placed in source order.

Set it higher for calmer, more left-to-right flow. Set it lower (including 0) for strict shortest-column placement.

Waterfall vs Brick

Define grid-template-columns to get a waterfall (column-first) layout. Define grid-template-rows to get a brick (row-first) layout. The grid-auto-flow: normal default figures it out from which axis you define.

Spanning lanes

Use grid-column: span 2 to make an item span multiple lanes. Combined with auto-fill columns, this enables editorial layouts — hero items, featured cards — without row-based math.

No JavaScript required

Traditional masonry layouts required a JS library like Masonry.js to measure and position items. Grid Lanes handles this entirely in the browser's layout engine.

Accessibility

Tab order follows the HTML source order, not the visual column position. Users never get trapped tabbing to the bottom of one column before reaching the next. Screen readers follow the same order.

Placing items explicitly

You can use grid-column: -3 / -1 to pin an item to the last two lanes regardless of how many lanes the viewport creates. Great for sticky headers or nav areas inside the grid.

gap

The gap property works the same as regular CSS Grid. It applies between lanes and between items within a lane.

Browser support

Currently available in Safari Technology Preview 234+. The CSS Working Group has reached consensus on the core feature. Implementation in other engines is expected to follow. Watch webkit.org for updates.

Varying lane widths

Since lanes are defined with full grid-template-* syntax, you can mix sizes. For example: repeat(auto-fill, minmax(8rem, 1fr) minmax(16rem, 2fr)) minmax(8rem, 1fr) creates alternating narrow and wide columns where the first and last column are always narrow.
